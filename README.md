# 정보보안 용어 모음

외우는 자료가 아니라 **이해하는** 자료입니다. 용어사전이 '찾아보기'라면, 이 문서는 '한 번 제대로 잡기'입니다.

**→ [https://zz1231me.github.io/security-understand/](https://zz1231me.github.io/security-understand/)**

## 무엇인가

정보보안 핵심 개념 **267개**를 6단계로 정리한 단일 HTML 문서입니다. 각 개념마다 같은 여덟 칸을 채웁니다.

| 칸 | 역할 |
|---|---|
| 한 줄 핵심 | 이 개념을 한 문장으로 |
| 왜 이 이름인가 | 어원. 이름의 뜻이 개념과 연결되면 잘 잊히지 않습니다 |
| 비유로 잡기 | 일상 사물에 대응시켜 직관 만들기 |
| **구조 그림** | 계층·순서·시간축처럼 말로는 안 잡히는 개념 15개는 그림으로 |
| 실제로는 이런 장면 | 회의·진단결과서·관제보고서에서 마주치는 구체적 상황 |
| **흔한 착각** | 이 자료의 핵심. 대부분의 사람이 잘못 알고 있는 지점 |
| 이렇게 말하면 됩니다 | 회의에서 그대로 쓸 수 있는 질문 문장 |
| **연결 흐름** | `선수 개념 → 이 개념 → 후속 개념` 3단 그래프. 눌러서 바로 이동 |
| 제품 · 도구 | 오픈소스 · 상용 · 국내 제품. 오픈소스는 GitHub 스타 순 |

## 구성

| 단계 | 개수 | 누가 보는가 |
|---|---|---|
| 1 · 입문 · 기본 상식 | 31 | 전원. OSI 계층·IP·프로세스·파일 권한부터 |
| 2 · 실무 | 55 | 전원. 매일 듣는 용어 |
| 3 · 심화 | 67 | 진단·관제·개발보안 실무자 |
| 4 · 설계와 기술 판단 | 45 | 구조와 도구를 정하는 사람 |
| 5 · 관리와 규제 | 28 | 규제·예산·조직을 다루는 사람 |
| 6 · 전문 | 41 | 해당 직무 담당자 |

단계는 난이도가 아니라 **역할**입니다. 자기 역할에 없는 단계는 훑고 넘어가도 됩니다.

19개 분야(기초 · 거버넌스 · 시스템 · 네트워크 · 악성코드 · 암호 · 웹취약점 · 공격 · 솔루션 · 관제 · 포렌식 · 취약점 · 계정 · 클라우드 · 개발보안 · 진단 · 모바일 · OT보안 · AI보안)로 교차 필터링됩니다.

## 기능

- **연결 흐름** — 카드마다 `먼저 → 이 개념 → 이어서` 형태로 방향이 보이게 배치. **선수 링크 440개**를 직접 정의하고 후속은 역방향 자동 생성. 267장 전부가 흐름에 연결되어 있어, 목차 순서가 아니라 **의존 관계를 따라 읽을 수 있습니다**
- **구조 그림 15개** — OSI 7계층, 퍼듀 모델, VM과 컨테이너 대조, RTO/RPO 시간축, 침해사고 대응 흐름, 킬체인 7단계, TLS 핸드셰이크, Kerberos 티켓 5단계, 보안 통제 3×3 격자, 심층방어 겹구역, DMZ 구역, CIA 삼각, 봉투 암호화 등. 이미지가 아니라 **DOM으로 그려서** 다크모드와 화면 폭을 그대로 따라갑니다
- **학습 경로 모드** — 목표 개념을 고르면 **왼쪽에 학습 순서가 뜨고 오른쪽에 그 단계의 카드가 한 장씩** 펼쳐집니다. 연결 흐름 그래프를 거슬러 올라가 위상 정렬한 순서라 1단계부터 따라가면 막히지 않고, 화살표 키로도 넘길 수 있습니다
- **읽기 모드 / 플래시카드 모드** — 용어만 보고 설명이 떠오르는지 자기 점검
- **제품 · 도구 칸** — 개념 262개에 오픈소스·상용·국내 제품을 정리. 오픈소스 항목 1079개 중 830개에 GitHub 스타 실측값과 저장소 링크
- **읽기 모드도 단계별 페이지** — 좌측에 단계 목록(건수 포함), 우측에 그 단계 카드만. 267장을 한 스크롤에 쏟지 않습니다. 각 단계 안에서는 분야 바로가기로 건너뛰고, 검색·분야를 지정하면 단계를 넘나들며 전부 찾아줍니다
- 라이트 / 다크 모드 (시스템 설정 자동 추종, 선택은 저장됨)
- 키보드: `/` 검색 · `←` `→` 카드 이동 · `Space` 뒤집기
- 맨 위로 버튼 (스크롤 시 표시)
- 인쇄 레이아웃 포함
- **의존성 없는 단일 파일** — `index.html` 하나로 끝, 빌드 과정 없음
